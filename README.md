# Luis O. Florencio — Portfólio

Release 1.0 preparada para GitHub Pages.

## Publicação recomendada

1. Crie/renomeie o repositório para `lteodoro780.github.io`.
2. Envie **o conteúdo desta pasta para a raiz** da branch `main`.
3. Em **Settings → Pages**, escolha **Deploy from a branch**, `main` e `/(root)`.
4. Após publicar, confirme **Enforce HTTPS** em **Settings → Pages**.
5. URL esperada: `https://lteodoro780.github.io/`.
